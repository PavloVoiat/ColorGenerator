# 🎨 Генератор цветов

Простой и удобный инструмент для генерации случайных цветов и их оттенков. Проект доступен по адресу: [pavlovoiat.github.io/ColorGenerator](https://pavlovoiat.github.io/ColorGenerator)

## ✨ Возможности

- Генерация случайного основного цвета
- Автоматическое создание набора гармоничных оттенков
- Отображение цветов в HEX-формате
- Быстрое копирование цвета в буфер обмена
- Возможность сбросить текущую палитру и начать заново

## 🚀 Использование

1. Откройте страницу приложения.
2. Нажмите кнопку **«Новый цвет»**, чтобы сгенерировать новую цветовую схему.
3. Нажмите на любой из цветовых блоков или на HEX-код, чтобы скопировать его.
4. Используйте кнопку **«Скопировать всё»**, чтобы скопировать все HEX-коды палитры.
5. Кнопка **«Сбросить»** возвращает палитру к исходному состоянию.

## 🛠️ Локальный запуск

Чтобы развернуть проект локально:

```bash
git clone https://github.com/pavlovoiat/ColorGenerator.git
cd ColorGenerator
# Откройте файл index.html в любом современном браузере
```
